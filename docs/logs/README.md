# ローカル専用ログ

このディレクトリは、開発中の会話ログや実機診断メモをローカルで保管する場所です。Markdownログは`.gitignore`でGit対象外にしています。

## 置いてよいもの

- 開発作業の要約やClaude Codeとの会話ログ
- 端末での調査手順と、識別情報を除いた結果

## 置かないもの

- 生の計測CSV、正確なGPS座標や移動時刻
- Cell ID、加入者識別子、電話番号、アカウント情報
- ADB bugreport/logcatの未確認ダンプ、秘密鍵、トークン

CSVや端末診断が必要な場合は、まずユーザー端末内に保管します。共有が必要なら、識別情報を削除・粗粒度化した複製を作り、公開リポジトリへ入れる前に内容を確認します。

`.gitignore`は、すでに追跡されているファイルには効きません。ローカルログをここへ置く前後に`git status --short`と`git ls-files`で追跡状態を確認してください。
