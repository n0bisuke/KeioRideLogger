# 発表者用：導入と話のつなぎ

スライドの文章を読むのではなく、聞き手を「疑問 → 観測方法 → 実測 → 次の検証」へ案内するための短い話し言葉メモです。実乗車データを示すまでは、結果を断定しません。

## OP：テーマをひとことで

「京王ライナーで電波を測ってみます。電車が動くと、スマホの通信はどう変わるのか。今日はAndroidで記録して、隣のブラウザで見てみます。」

## 自己紹介

「菅原のびすけです。プロトタイピング専門スクールのプロトアウトスタジオに関わり、IoTLTを主催しています。今日は、作ったものを実際の移動の中で試すLTです。」

## 掴み：トンネルとスマホ

「トンネルに入ると、スマホの通信が不安定になったように感じることがあります。でも、GPSが止まっただけで通信断やトンネル進入が分かったとは言えません。何を一緒に記録すれば、その変化を確かめられるでしょう？」

## 乗車区間と問い

「今回の舞台はMt.TAKAO 3号です。新宿を出て明大前を通り、高尾山口へ向かうこの移動で、通信の変化を位置や時刻と一緒に見ます。駅の予定時刻は目安として置き、通過時刻や観測結果は実測で確かめます。」

## 観測テーマへ

「位置だけでは足りないので、在圏セル、電波品質、通信応答、端末センサーを同じ時刻に並べます。まず、今日見たい4つの変化を整理します。」

## Androidを選ぶ理由へ

「GPSの軌跡だけなら、スマホのOSにこだわる必要はありません。今回は、Androidの公開APIから取得できる在圏セルや電波の値も観測したいのでAndroidを使います。端末やOSによって取れない値がある点も、そのまま記録します。」

## 計測からブラウザへ

「値を取るだけで終わると、あとからCSVを開くまで変化に気づけません。そこで記録を続けながら、近くのMacのブラウザにもライブ表示します。」

## BLEを選んだ理由へ

「車内では携帯回線が弱くなる可能性があります。ライブ表示をその回線に依存させたくない。USBケーブルと中継プログラムもデモの故障点になるので、AndroidからBLEでブラウザへ直接渡す構成にしました。CSVは別に残します。」

## グラフから読み方へ

「地図やグラフに線が出ても、それだけで原因まで分かったわけではありません。在圏セルの変化は観測候補として扱い、RSRPやHTTP応答、GPS欠測とは別の指標として重ねます。」

## トンネル・センサーへ

「トンネル区間は事前に分かっている位置情報と、当日のGPS・電波・通信観測を分けて見ます。気圧や加速度も手掛かりにはなりますが、端末の持ち方や車内環境の影響があるので補助データです。」

## キャラクターから実験へ

「ムッちゃん風のオリジナルキャラクターは、速度を直感的に見せる演出です。列車の公式速度ではなくGPSの推定速度に反応します。見た目の楽しさと、通信を確かめる実験は分けて考えます。」

## まとめへの着地

「最初は電波を測るつもりでしたが、GPSやセルの変化、加速度など、モニタリングすると見えるものが増えました。Wi-Fiスキャンも次に試したい。初めての本格Kotlinアプリ開発をコンテナの中、IDEなしで進められたのも大きな発見です。京王・高尾山のキャラクターから速度連動の表現を考えたり、みんなでログを集めて旅のマップにしたり、Androidネイティブで広がる選択肢をこれからも試していきます。」

## スライド間のひと言

- **OP → 自己紹介:** 「あらためまして、菅原のびすけです。普段はプロトタイピングやIoTLTに関わっています。」
- **自己紹介 → 掴み:** 「今回は作ったものを現場で試す題材として、京王ライナーに乗って電波を見てみます。」
- **掴み → 乗車区間:** 「この変化を確かめる舞台は、新宿から高尾山口へ向かうMt.TAKAO 3号です。」
- **乗車区間 → 4つの観測テーマ:** 「GPSだけでは通信の中身は分かりません。在圏セル、電波、応答、端末センサーを並べます。」
- **観測テーマ → エリアマップ:** 「この変化は沿線のどこで起きるのか。まず公式エリア情報と、端末の実測は別物だと整理します。」
- **エリアマップ → Android:** 「エリアマップはサービス範囲の目安です。乗車中に端末がどのセルを使い、何を受信したかはAndroidで記録します。」
- **Androidの取得値 → BLE構成:** 「値を取れるだけでなく、その場で変化を見たい。そこで携帯回線に依存しないBLEを選びました。」
- **CSV・グラフ → セル変更:** 「地図と時系列が揃うと、セルの変化を場所と時間に結びつけられます。ただし、変化の記録だけで基地局の切り替えを確定はしません。」
- **セル変更 → トンネル:** 「トンネルも同じで、GPS欠測だけでは断定できません。既知の区間、電波、通信応答、センサーを分けて重ねます。」
- **観測機能 → キャラクター:** 「ここまでが観測の中身です。最後に、移動速度を直感的に伝えるキャラクターと、作ってみて分かったことを紹介します。」
- **開発環境 → 次の乗車:** 「作るところまでは来ました。次は乗車中に実測して、何が取れたかをみんなのログにも広げてみたいです。」
