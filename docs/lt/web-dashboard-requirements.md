# 京王ライナー ネットワーク観測 Web デモ要件

## 目的

京王ライナーで移動しながら計測したGPS・携帯網・HTTP応答の変化を、LT会場で一目で伝わるダッシュボードとして見せる。見本画像の「大きな路線地図＋右側の指標カードとセル変更履歴＋下段の時系列グラフ」という構成を目標にする。

現在のCSVビューアをまずデモ画面へ整え、その後BLEリアルタイム接続を追加する。CSV表示中にBLE接続中と誤認させる表示や、実データにない駅・速度・セル変更は出さない。

## 画面構成

### ヘッダー

- タイトル「京王ライナー ネットワーク観測」と、短い説明を表示する。
- データソースと状態を区別して表示する。CSV読込時は「CSV再生/読込済み」、BLE時は実際のGATT接続状態と最終受信時刻を表示する。
- 表示時刻は計測時刻または現在時刻のどちらかを明示し、CSVの計測時刻をリアルタイム時刻のように見せない。

### メイン領域

- 左側の約2/3にOpenStreetMap背景地図とGPS軌跡を配置する。開始・終了、速度による軌跡色、水平精度の円、セル変更候補を重ねる。
- GPSの実測軌跡を基本とし、京王線路や駅間を補間して実測のように描かない。駅名を独自に割り当てる場合は、位置推定/参考情報と分かる表示にする。
- 右側に速度、在圏セルのRAT、RSRP、最新HTTP応答時間のカードを配置する。値の取得時刻と欠測/古さが分かり、未取得を0で埋めない。
- 右下にセル変更履歴テーブルを置く。時刻、前後の観測セル、状態を表示し、候補・複数観測で裏付けられた変化・不確定を区別する。`baseline`を切り替わりに数えず、単発観測を確定handoverと呼ばない。

### 時系列・フッター

- 下段全幅にRSRPとHTTP応答時間の時系列を並べる。単位が異なるため軸と凡例を明確に分ける。通信失敗/タイムアウトは点や記号で表示し、値を持たない区間を線でつながない。
- セル変更候補は時刻位置にマーカーを付ける。地図、グラフ、履歴テーブルの選択時刻を連動させる。
- フッターにCSV記録/再生またはBLE接続状態、計測経過時間、受信イベント数を表示する。記録中、再生中、BLE接続中を混ぜない。

## データ・動作要件

- **CSVモード（先行）:** CSVはブラウザ内で解析し、ページサーバーへアップロードしない。既存の時間範囲スライダー、軌跡、グラフ、選択同期を維持する。
- **BLEモード（後続）:** HTTPS上の対応ブラウザでユーザー操作により接続する。受信した最新データを画面に反映し、BLE未接続/非対応/権限拒否/切断/データ停止を明示する。受信内容を外部APIや保存領域へ送らない。
- 表示値は実際にアプリ/CSV/BLEから届いた値のみ。デモ用の架空値を混ぜる場合は、明確なデモデータモードに分離し実測値と同じ画面で混同させない。
- GPSなし、GPS更新停止、セル情報なし、probe失敗、空データの各状態を画面内で説明し、他の可視化を止めない。
- デスクトップ/LT投影で読みやすいことを優先し、狭い画面では地図、指標、履歴、グラフの順に縦積みする。

## 地図タイルと外部通信

- LTデモでは背景地図を使う。OpenStreetMap標準タイルを表示する場合、地図上に「© OpenStreetMap contributors」のリンクを常時表示し、[タイル利用ポリシー](https://operations.osmfoundation.org/policies/tiles/)に従う。
- 背景地図を表示すると、タイル提供元に利用者のIPアドレスと表示範囲を示すタイル座標が伝わる。画面上で説明し、地図をオフにできるようにする。
- CSV本体、Cell ID、個々のGPS測位点を地図提供元やサーバーへ送らない。ジオコーディング、経路検索、クラウド解析は追加しない。
- 地図タイル取得に失敗/オフラインでも、GPS軌跡・グラフ・CSV解析を続ける。

## 優先タスク

1. 現在のCSVビューアを見本画像のダッシュボード配置に整える。実CSVの指標・イベントを対応カード、履歴、グラフへ割り当てる。
2. OSM背景地図、タイル帰属、外部送信の説明、地図オフ/オフライン時の挙動を実ブラウザとPages上で確認する。
3. CSVモードのデータソース表示、値の鮮度、未取得/失敗状態を仕上げる。
4. Android BLE送信とWeb Bluetooth受信が実装された後、同じダッシュボードにBLEモードを追加し、接続・切断・再接続を実機と発表用ブラウザで確認する。

## 完了条件

- 実CSVを読み込み、地図上の軌跡、4つの指標カード、セル変更履歴、RSRP/HTTP時系列が欠測や値の古さを誤認させずに表示される。
- 地図・グラフ・履歴の時刻選択が連動し、画面をLT投影で読める。
- CSVモードとBLEモードを表示上区別し、BLE未接続を接続中と見せない。
- OSMタイルの帰属と送信情報の説明が見え、地図タイル以外へCSV/座標が送信されない。
- 実データのない移動やハンドオーバーを作らず、ローカルCSVをリポジトリへ追加しない。
