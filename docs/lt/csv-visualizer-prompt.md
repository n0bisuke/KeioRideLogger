# Claude Code指示: CSVローカル可視化Webアプリ

下記をリポジトリルートでClaude Codeへ渡してください。

```text
Keio Ride Loggerの計測CSVをブラウザ内で読み込み、地図風のGPS軌跡と時系列グラフを表示するローカルWebビューアを実装してください。コードを書いて機能を完成させ、変更点と使い方を報告してください。

## 最初に確認すること

- リポジトリルートのAGENTS.md、README.md、docs/DEVELOPMENT_STATUS.md、docs/ROADMAP.md、android-app/AGENTS.mdを読む。
- android-app/app/src/main/kotlin/.../data/CsvFormat.kt と LogEvent.kt、CSV列を説明したREADMEの記述を読み、実際のCSV形式に合わせる。
- Dockerfile、compose.yamlの構成を確認する。AndroidコードやAndroidビルド設定は変更しない。
- 現在のGit変更を確認し、既存のユーザー変更を上書き・巻き戻ししない。

## 作るもの

- リポジトリ直下に`web/csv-visualizer/`を作り、依存ライブラリなしのHTML/CSS/JavaScriptで実装する。
- `index.html`をブラウザで開いて使える自己完結型のローカルツールにする。Node.js、バックエンド、外部CDN、地図タイル、外部APIを追加しない。
- 画面からCSVファイルを選び、内容をブラウザ内メモリだけで解析する。CSVをアップロード・送信・永続保存しない。ファイル名・GPS座標・Cell IDをconsoleや外部通信へ出さない。
- 利用手順と対応CSV形式を`web/csv-visualizer/README.md`に書く。サンプルに実機CSVや個人情報を含めない。

## 表示要件

1. セッション概要: 計測時間、イベント総数、GPS件数、登録済みセル観測数、観測されたセル変更候補数を表示する。行がない/値が空の項目は0や成功として扱わず「データなし」と区別する。
2. GPS軌跡: CSVの`gps`行のlat/lonを使ってSVGまたはCanvasに描く。外部地図タイルなしで完結させる。点を選ぶと取得時刻、速度km/h、水平精度を表示する。精度が悪い点はスタイルで区別し、精度円も表示できる範囲で表現する。GPS欠測の区間を直線でつながない。
3. 時系列グラフ: GPS速度（m/sからkm/hへ換算）と登録済みセルのRSRP（dBm）を、別々のグラフ・単位で表示する。同じイベント行にない値を補間して同期したように見せない。横軸は計測開始からの経過時間とする。
4. セルイベント: `cell`行の`registered`を使い在圏セルと周辺セルを区別する。`cell_change`行がある場合は変更候補として時系列と軌跡上に印を付ける。最初の在圏セルをhandoverとして数えない。イベントがない場合は、切り替わりがなかったのか登録済みセルを取得できなかったのかCSV状態列を確認し、区別できなければその旨を表示する。
5. フィルタや点選択を地図風軌跡とグラフ間で連動させる。画面幅が狭い場合も操作できるレイアウトにする。
6. CSV読み込み前、形式不一致、壊れた行、GPSなし、セル情報なし、空ファイルを分かりやすく表示する。部分的に読める場合は全体をクラッシュさせず、読み飛ばした行数を示す。

## CSV処理と正確さ

- CSVヘッダー、UTF-8、引用符で囲まれたカンマ/改行/二重引用符、LFに対応する。単純な`split(',')`だけで実装しない。
- 実データのイベント名と列名を確認し、未知の列・イベントがあっても読み込み全体を壊さない。
- 時刻は`time_utc`または`elapsed_realtime_ns`の実際の意味を確認して並べる。日時が無効なイベントを推測で配置しない。
- 速度、RSRP、Cell ID等の数値を欠損値と混同しない。空欄を0にしない。
- セルは`registered=true`を在圏セルとして扱い、`registered=false`の周辺セルを在圏セルやhandoverとして数えない。
- 地図表示はGPS座標そのものから描く軌跡図とし、駅・線路へのスナップや正確な鉄道位置を装わない。画面に「GPS軌跡・概略」と明記する。
- 座標はブラウザ内だけで扱う。外部タイルや地理APIにアクセスしない。

## デザイン

- 日本語UI、ダーク基調、計測の読み取りやすさを優先する。
- 画面上部にファイル選択とセッション概要、主領域に軌跡図、下部に速度・RSRPグラフとセル変更時系列を配置する。
- 色だけに頼らず、凡例・線種・ラベルでも在圏セル/周辺セル/GPS精度を区別する。
- アプリの京王ライナー計測が主題だが、京王の公式ロゴ・公式キャラクター画像は使わない。
```
