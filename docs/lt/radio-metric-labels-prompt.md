# Claude Code 指示: 電波グラフ見出しを分かりやすくする

## 目的

Webビューアの時系列グラフにある専門的な見出しを、初見の人にも意味が伝わる日本語へ置き換える。RSRPなどの指標名と単位は正確さのため残す。

## 対象

`web/csv-visualizer/assets/app.js` の時系列グラフ見出し:

- 現在: `在圏セル RSRP [dBm]`
- 変更後: `受信電波の強さ（RSRP）[dBm]`
- 現在: `在圏セル RSRQ・SINR/RSSNR [dB]`
- 変更後: `受信電波の品質（RSRQ・SINR/RSSNR）[dB]`

トップページと `/keio-mttakao3/` は共通実装を使うので、両方に反映する。

## 実装上の注意

- グラフの値、時系列、色、線種、凡例、選択同期、再生、単位は変えない。見出しの文言だけを変更する。
- RSRPとRSRQ・SINR/RSSNRを別パネルのまま保つ。
- カードや選択時刻の詳細にある指標名は今回の対象外。別の文言へ広げない。
- ダークテーマ、一覧/詳細モード、狭い画面で見出しが不自然に折り返したり隣のグラフに重なったりしないことを確認する。
- リポジトリ内の現在の変更を確認し、関係のない作業を上書きしない。

## 受け入れ条件

1. 両ページで上記2つの見出しが新しい表現になっている。
2. RSRPの単位は `[dBm]`、品質グラフの単位は `[dB]` のまま。
3. 凡例はRSRQとSINR/RSSNRの系列を従来どおり識別できる。
4. CSV再生カーソルと時刻同期、グラフの値・表示に回帰がない。
5. ブラウザでトップ/ LTページの一覧・詳細表示を確認し、結果を `docs/TEST_LOG.md` に記録する。

## 完了報告

変更ファイル、表示確認した画面、実行した検証、未確認事項を簡潔に報告する。
