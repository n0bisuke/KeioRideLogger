# GPS標高表示の実装指示

## 目的

移動モニターにGPSで記録した高度を表示し、移動に沿った高さの変化を時系列で確認できるようにする。散歩・ドライブの検証にも、京王ライナー乗車時の軌跡と補助情報にも使える共通機能とする。

## 今回の実装範囲

### 1. GPS高度をCSVから読み取る

- GPSイベントの `altitude_m` を数値として読み、時刻とともに保持する。空欄・不正値は `null` として扱い、0 mに置き換えない。
- GPSの時刻・緯度経度・速度・水平精度の既存処理を壊さない。旧CSVに列がない場合も従来どおり表示する。
- GPS高度は「GPS高度」と表記し、地形図や測量値と同じ精度だと見せない。気圧から高度を推定・補完しない。

### 2. 高度を選択時刻とグラフに表示

- 右側の指標カードに選択時刻付近の「GPS高度」を追加する。値がない場合は「未取得」と表示する。
- 時系列に「GPS高度 [m]」グラフを追加し、既存の時間範囲スライダー・再生カーソル・選択時刻に同期する。
- 高度の欠測区間は線をつながない。平滑化で変化を隠さない。必要なら生値を保ったまま軽い視認性調整を検討し、実施した場合は方法を表示する。
- 一覧モードでは地図・通信グラフのワンビュー配置を維持する。高度グラフのために既存の重要グラフを画面外へ押し出さない。詳細モードでは標高グラフを十分な幅で見られるようにする。
- 選択点に対応する高度を明確にし、グラフの単位と縦軸を表示する。GPS高度の精度情報がCSVにない場合、垂直精度をあるように見せない。

### 3. デモとデバッグ

- `#demo` と `#debug` の高度データは明示的に架空値として生成する。軌跡に応じて少し変化する値を与え、高度グラフ・カード・再生同期を確認できるようにする。
- `DEBUG · 架空データ` の識別を維持する。実測CSVや既存のセル履歴・BLE値をデモ値で上書きしない。
- `#debug` で高度が変わることと、時刻スライダー/再生に追従することを目視確認する。

## 地図・外部標高データについて

- 今回はOpenStreetMap標準タイルに標高データが含まれるとは扱わない。背景地図タイルから高さを推定しない。
- 今回の高度表示にはCSV内の `altitude_m` のみを使う。外部の標高API、DEM/地形タイル、地形データの一括ダウンロード、3D地形ライブラリは追加しない。
- CSVやGPS座標を外部標高サービスへ送信しない。
- 将来の3D地形表示は別タスクとし、候補データ提供元、利用条件、APIキー/CORS、通信量、オフライン時の表示、座標送信の説明を調べてから設計する。地形上にGPS軌跡を重ねる場合も、今回のGPS高度プロフィールと混同させない。

## ドキュメント

- `web/csv-visualizer/README.md` と `docs/lt/web-dashboard-requirements.md` にCSV高度の扱い、GPS由来の誤差、気圧と混ぜないことを記す。
- 実装内容・確認内容・未確認事項を `docs/TEST_LOG.md` に記録する。

## 受け入れ条件

1. 新形式CSVで `altitude_m` がカードとグラフに出る。
2. 高度の空欄/列のない旧CSVで `0 m` と誤表示せず、「未取得」またはグラフ欠測になる。
3. 表示時間帯、再生カーソル、選択時刻に高度表示が同期する。
4. 加速度・気圧の表示定義を変えず、気圧を標高へ換算しない。
5. 一覧モードの既存ワンビューレイアウトと、詳細モードの履歴スクロールを壊さない。
6. `#debug` で変化する架空高度の表示・再生を確認できる。架空データ表示が明瞭。
7. 外部APIへGPS座標を送らない。OpenStreetMapタイル利用時の帰属表示など既存の条件を保つ。
8. 既存のCSV/BLE解析、再生、セル履歴に回帰がない。実行した構文/テスト確認と実ブラウザ確認をログに残し、未確認は明記する。
