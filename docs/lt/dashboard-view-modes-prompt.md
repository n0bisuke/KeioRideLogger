# Claude Code 指示: ダッシュボードの一覧/詳細モード

このリポジトリの `AGENTS.md` と `docs/lt/web-dashboard-requirements.md` を先に読み、現在の `web/csv-visualizer/` の実装を確認してください。スクリーンショットではセル変更履歴が増えると右カラムが縦に伸び、地図や時系列の配置が崩れていました。既存データ表示を活かし、画面上のボタンで一覧モードと詳細モードを切り替えられるようにしてください。

## 目的

- `一覧`: デスクトップで地図・主要指標・イベント・グラフを一目で俯瞰するダッシュボード。
- `詳細`: 現在の縦長表示を活かし、履歴やグラフを大きくしてスクロールしながら読む表示。

トップの移動モニター(`/`)とLTページ(`/keio-mttakao3/`)の両方で使える共通機能にしてください。表示モード以外の計測値やBLE/CSVの意味は変えないでください。

## CSVなしのデモモード

- `#debug` を付けて開くと、CSVファイル選択なしにデバッグデータを読み込み、地図・カード・イベント・グラフ・再生を確認できるようにする（例: `/#debug`、`/keio-mttakao3/#debug`）。デバッグ用の画面ボタンは置かず、通常はCSV選択とBLE接続を主操作にする。
- デモ/デバッグは公開可能な架空データをコードから生成する。実測CSVの座標、Cell ID、PCIなどの識別情報をコピー・同梱しない。表示中はヘッダーと通知に `DEBUG · 架空データ` 等と明示し、実測/ライブ値と混同させない。
- 添付された短時間セッションのデータ量・観測頻度・計測の傾向を参考にする場合も、位置とネットワーク識別情報は架空に置き換える。Cell changeが実測で確認されていない元データを、切替実績として演出しない。
- デモデータはCSV表示・再生の経路を通し、一覧/詳細モード、時間スライダー、再生ボタンを同じ実装で操作できること。
- 追加の確認用URLとして `/#debug` と `/keio-mttakao3/#debug` を受け付ける。CSVを読み込んだ状態を再現する架空データを自動投入し、`DEBUG · 架空データ` の表示で実測と区別する。生CSV、座標、セル識別情報を公開データに含めない。

## UIとレイアウト

- ヘッダーまたは画面上部の常に見つけやすい位置に、`一覧`と`詳細`のボタン/セグメント切替を置く。現在のモードを視覚・アクセシビリティ両方で示す。
- 初期表示は`一覧`。モードの好みは現在のページを開いている間だけ保持し、localStorage等へ保存しない。
- `一覧`はデスクトップ16:9画面でブラウザ全体の縦スクロールを発生させず、接続状態と主操作、（LTページのみ）予定ルート概要、GPS地図、主要指標カード、イベント要約、通信品質グラフが見えるようにする。現在の`body.onescreen` CSSを読み、重複する仕組みを作らず整理する。
- 視覚的な優先順位は通信グラフを最優先にする。RSRP/RSRQ/SINRとHTTP応答時間などの時系列グラフには画面内で十分な幅と高さを割り当て、指標カードより大きく目立たせる。グラフをカード群の下に押し出したり、過度に低くしたりしない。
- 一覧の指標カードは値を素早く読むための小さなサマリーにする。余白・見出し・数値サイズ・説明文の占有高を抑え、同じ優先度のカードは整ったコンパクトなグリッドにする。長い補足文は一覧では省略または短文化し、意味と単位は詳細表示や既存の説明で確認できるようにする。
- 一覧のセル変更履歴は、全件を高さ固定のパネル内でスクロール表示する。合計件数も示す。履歴の件数にかかわらずパネル/グリッド/地図の高さを固定範囲内に保つ。
- `詳細`は現行の縦スクロールレイアウトを基本的に維持し、全セル履歴、既存の全時系列グラフ、補助センサー等を表示する。履歴が増えてもページレイアウトを不安定にしない。
- 一覧の中で履歴を内部スクロールさせる場合は、一覧の地図やグラフを押し下げない固定最大高とし、一覧に必要な最新イベントが見えること。
- 画面高が足りない場合やモバイル幅では、文字・ボタン・グラフを潰さずに縦スクロールへ切り替える。デスクトップの一覧基準は目安 1920×1080、16:9。
- 表示切替時にCSV/BLEの現在モード、選択中時刻、表示時間範囲、地図の選択状態を維持する。Canvasグラフ/地図は切替後にサイズを再測定して再描画し、空白や歪みを出さない。
- 一覧/詳細の状態はBLEライブ受信・CSV再生状態と分離する。CSV再生機能が実装済みの場合は、表示モード変更で再生を止めたり時刻を飛ばしたりしない。
- 秋葉原等のルート外検証中に、LTページで「乗車中」と誤認させない表示を維持する。予定ルートと実GPS軌跡は別に見せる。

## 用語

地図の◆凡例、セル履歴、グラフ凡例で、利用者向けの `観測変更候補` は `接続アンテナエリアの変化（推定）` にする。短いスペースでは「アンテナエリアの変化（推定）」としてもよい。説明には、記録された在圏セル情報からの推定であり、物理的な電波塔/アンテナの切替を確定したものではない旨を表示する。内部CSVのイベント値やデータ形式は変更しない。

## 完了条件

1. 一覧/詳細をボタンで切り替えられ、初期状態は一覧。
2. デスクトップ16:9の一覧で主要情報が一画面に収まり、画面の高さが固定される。
3. 一覧では指標カードがコンパクトにまとまり、通信グラフがカードより広く/高く表示されて主役として読める。
4. セル変更候補を1件から多数に増やしても、一覧のカード、地図、グラフの位置やサイズがずれず、履歴枠をスクロールして全件を確認できる。
5. 詳細ではセル履歴全体、全グラフ、補助表示を縦スクロールで確認できる。
6. 切替前後で同じCSV/BLE値・選択時刻・表示範囲が保たれ、Canvasが正しい寸法で再描画される。
7. 日常移動ページとLTページの両方で動作し、狭い画面では読みやすい縦レイアウトになる。
8. `/#debug` と `/keio-mttakao3/#debug` を直接開くと架空データが読み込まれ、出所が明示される。再生でき、CSVファイルを選ばなくても画面を確認できる。
9. `/#debug` と `/keio-mttakao3/#debug` も直接読み込みでき、debugラベルを表示する。ページを再読み込みしても同じ架空データで確認できる。
