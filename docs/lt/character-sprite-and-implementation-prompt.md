# 速度連動キャラクター素材と実装指示

## 素材

- アプリ用スプライトシート: [`glider_speed_sheet.png`](../../android-app/app/src/main/res/drawable-nodpi/glider_speed_sheet.png)
- 画像サイズ: 1774 × 887 px、透過PNG
- 配置: 4列 × 2行。左上から7コマを使用し、右下の8コマ目は空き。
- コマの順番: 停止、ゆっくり歩き、普通歩き、走る、自転車くらい、車くらい、京王ライナー高速域。
- キャラクター: ムササビを題材にしたオリジナルの8bit風グライダー。既存のムッちゃんの画像・衣装・顔・設定を複製したものではない。

スプライトシートは画像生成による初稿です。各コマの境界を等分で切り出し、Android上で7状態に使います。画像の見た目やコマ境界に問題があれば、実装前にシートを目視して調整します。右下の空きコマは描画しません。

## 速度状態

GPSの速度をm/sからkm/hへ変換し、以下の帯に分類します。これはアプリに実装済みの初期仕様で、Webも同じ境界を使います。実車CSVで妥当性を確認した後に変更する場合は、Android・Web・この資料を同時に更新してください。

| 状態 | 初期速度帯 | 表示 |
|---|---:|---|
| 停止 | 0以上、1未満 km/h | 翼をたたんで座る |
| ゆっくり歩き | 1以上、3未満 km/h | 小さな一歩 |
| 普通歩き | 3以上、6未満 km/h | 歩行ポーズ |
| 走る | 6以上、15未満 km/h | 走行ポーズ |
| 自転車くらい | 15以上、30未満 km/h | 低い姿勢で滑空 |
| 車くらい | 30以上、90未満 km/h | 前傾して滑空、風の表現 |
| 京王ライナー高速域 | 90 km/h以上 | 飛膜を大きく広げた滑空 |

60 km/hは「車くらい」の状態に含まれます。車の実速度は道路・渋滞・制限によって変わり、高速道路では列車の速度帯と重なります。この分類はGPS速度に対するキャラクター演出であり、実際に車・自転車・列車のどれに乗っているかを判定するものではありません。

60 km/hは「車くらい」の帯、90 km/h以上は「京王ライナー高速域」の演出帯です。5000系の車両資料にある京王線の運転最高速度110 km/hは、Mt.TAKAO 3号の実測速度や時速の調査結果ではありません。GPS速度は列車の速度計ではなく、線区や走行状況により最高速度へ達するとは限らないため、「実測最高速度」と誤解させないでください。[J-TREC車両資料](https://www.j-trec.co.jp/company/070/07/jtr07_032-039.pdf)

速度はGPSのノイズで状態が頻繁に切り替わらないよう、数秒間の平滑化とヒステリシスを入れます。新しい位置が一定時間届かなければ速度状態を「GPS待ち/不明」にし、古い速度のままアニメーションを続けません。停止判定はGPS誤差を踏まえて実車データで調整してください。

Android側の既存速度帯・平滑化をWebでも再現する方針は、[LTデモ用Webダッシュボード要件](web-dashboard-requirements.md)を参照してください。

## 他のAIへ渡す実装指示プロンプト

作業前にリポジトリルートのAGENTS.md、android-app/AGENTS.md、README.md、関連するCompose画面とGPS状態管理コードを読み、既存の構成・Docker/OrbStack開発手順に従ってください。Android SDK/Gradle/ビルドは必ず既存コンテナ内で実行し、MacホストにAndroidビルドキャッシュを作らないでください。

挙動:
- 既存のGPS測定とUI状態を再利用し、GPS権限、位置収集、CSVの形式や記録頻度を今回の表示機能のために変更しないでください。

## Webダッシュボード実装指示

Web側ではトップの移動モニターと `/keio-mttakao3/` の両方にキャラクターを表示します。WebはGitHub Pagesの `web/csv-visualizer/` だけを公開するため、Androidリソースを実行時に相対参照できる前提にせず、同じオリジナルスプライトシートをWeb配下のアセットとして同梱してください。Android版を正本として、コピー元・更新手順をコメントまたはREADMEに記録し、公式キャラクター画像やロゴは含めません。

```text
Keio Ride LoggerのWebビューアへ、Android版と同じオリジナル8bit風ムササビキャラクターの速度連動表示を追加してください。

作業前にルートのAGENTS.md、README.md、docs/lt/web-dashboard-requirements.md、docs/lt/character-sprite-and-implementation-prompt.mdを読み、既存のCSV解析・BLE受信・画面構造とgit statusを確認してください。進行中の変更を上書きせず、関係のないファイルを整形しないでください。

表示対象:
- `web/csv-visualizer/` の移動モニター (`/`) と `keio-mttakao3/` の両方。
- BLEライブではAndroidが送るGPS速度/精度/時刻を使う。CSVでは既存CSVのGPSイベントを時刻順に再生し、選択中の時間範囲と連動させる。
- Androidアプリと同じ7段階、直近5秒の有効速度の中央値、境界ヒステリシス `max(0.5 km/h, 境界値の10%)`、水平精度30m以内、GPS更新から5秒以内を適用する。重複した別仕様をページごとに作らない。可能なら既存の速度判定関数を共有する。
- 速度帯: 停止 `[0,1)`、ゆっくり歩き `[1,3)`、普通歩き `[3,6)`、走る `[6,15)`、自転車くらい `[15,30)`、車くらい `[30,90)`、ライナー高速域 `[90,∞)` km/h。60 km/hは車くらい。90以上は速度の演出ラベルで、列車を検出した意味ではない。高速道路の車も同じ帯に入る場合がある。
- GPS未取得、速度欠測、精度不足、5秒超の更新停止では「GPS待ち/不明」とし、0 km/hや最後のキャラクターを現在状態のように表示し続けない。CSVの再生時刻とBLEの実時刻の扱いを分ける。
- キャラクターの近くに速度値と状態ラベルを表示し、ネットワーク指標・セル履歴・地図の可読性を妨げない。動きや乗車モードの自動推定とは説明しない。
- ライブ、CSV、サンプル/リプレイの表示モードを明示する。サンプル値は画面全体でサンプルと分かるようにする。
- キャラクター素材はこの資料で指定するオリジナルスプライトのみを使う。ムッちゃんの公式画像・公式衣装・ロゴを複製しない。スプライトの各コマは4列×2行から左上の7コマを使い、右下は空き。nearest-neighbor相当でピクセル感と縦横比を保つ。
- CSV/BLEデータはブラウザ内だけで処理し、アップロード・永続保存・外部送信を追加しない。

完了条件:
- 2ページとも同じ速度データに対して同じキャラクター状態を表示する。
- 停止、60 km/h、90 km/h境界の上下、GPS欠測、精度不足、5秒超のstaleを確認する。
- BLE切断やCSVの範囲変更後に古いキャラクター状態を残さない。
- GitHub Pagesのプロジェクト配下パスでアセットを読み込める。データを外部送信しない。
- 変更ファイル、実行した検証、未確認の実機条件を報告する。
```

## 実機で先に確かめること

1. GPS速度が屋外・乗車中にどの程度の周期と精度で更新されるか。
2. 速度帯が数秒ごとに過剰に揺れない平滑化・切替条件。
3. トンネルや測位ロストで「不明」に切り替わり、古い値を実測中のように見せないこと。
4. スプライトが暗い画面でも見え、Compose UIの他の状態表示と競合しないこと。
