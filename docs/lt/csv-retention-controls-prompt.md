# Claude Code指示: CSV記録の選択とアプリ内ファイル削除

以下をリポジトリルートでClaude Codeに渡してください。関連TODOは[`docs/ROADMAP.md`](../ROADMAP.md)の「CSV記録のオン/オフとアプリ内計測ファイルの一括削除を追加する」です。

```text
Keio Ride Loggerの計測開始前にCSV記録の有無を選べるようにし、アプリ内に蓄積したセッションCSVを一覧・全件削除できるようにしてください。

## 現状と確認

- `RecorderViewModel.start()`が`filesDir/sessions`にセッションCSVを作成する。
- `SessionWriter`がイベントをバックグラウンドで追記し、約1秒ごとにflushする。stop時にwriterを閉じ、ファイル名を保存可能にする。
- `saveTo(uri)`はユーザーがSAFで指定したURIへアプリ内ファイルをコピーする。コピー後もアプリ内ファイルは残る。
- 作業前にルート/Android側AGENTS、README、Dockerfile、compose、Manifest、現在のGit差分、`RecorderViewModel`、`SessionWriter`、`SessionFiles`、保存UIを確認する。既存の未コミット変更を上書き・巻き戻ししない。

## CSV記録を選ぶ

1. 計測開始前に「CSVに記録する」スイッチを用意する。既定はオンとし、既存ユーザーの現在の挙動を維持する。セッション開始後は操作不能にする。
2. オフの場合はセッションCSVファイルも`SessionWriter`も作らず、イベントをディスクに永続化しない。GPS、セル、センサー、HTTP probeの既存収集、画面内ライブ表示、BLE共有（利用者が有効にした場合）は継続する。
3. 記録オフ中は画面に「CSV記録オフ・データは保存されません」と明示する。イベント数を表示する場合は、永続保存済み件数と誤認させないよう「CSV記録なし」等と状態を併記する。CSV保存ボタンと未保存ファイル案内は表示しない。
4. 既存の`lastFile`や`savableFileName`、保存完了状態が記録オフ時に前セッションのファイルを指さないよう、セッション開始/停止遷移を確認する。記録オフでも計測開始/停止やライブstateを壊さない。

## アプリ内CSV一覧と全件削除

1. `filesDir/sessions`にあるアプリ管理対象のセッションCSVだけを列挙し、ファイル名、時刻、サイズを表示する。一覧更新はIO dispatcherで行い、画面状態へ安全に反映する。
2. 「アプリ内の計測CSVをすべて削除」ボタンを追加する。計測中、writerが開いている間、flush/close中は無効にする。削除前に確認ダイアログを出し、対象件数と合計サイズ、取り消せないことを示す。
3. 削除対象をセッション用ディレクトリ内のCSVに限定する。アプリ設定、キャッシュ、他のファイル、任意のユーザー文書は削除しない。パス正規化/子要素確認などで対象範囲を守る。
4. SAFでDownloads等へ書き出したコピーは別のURIにある。アプリはそれらを列挙・削除しない。画面で「この操作はアプリ内のCSVだけを削除します。保存先へ書き出したコピーは残ります」と説明する。
5. 削除成功・失敗を個別件数で報告する。成功後に一覧、現在の保存対象、`savableFileName`、saved/message stateを更新し、削除済みファイルを保存しようとする古いボタン状態が残らないようにする。
6. 削除操作は計測停止後に限る。ファイル一覧が空なら削除ボタンを無効化する。削除確認なしに起動時・容量不足時の自動削除はしない。

## テストと完了報告

- ファイル一覧の並び、CSV以外を削除しないこと、全件/空一覧/部分削除エラー、active writer中の拒否、CSV記録オフでファイルを作らないことをテストする。
- 記録オンの回帰としてイベント追記、stop後のflush、SAF書き出しが維持されることを確認する。
- Docker/OrbStack内で既存のAndroid build・関連テスト・lintを実行する。ホストにSDK/Gradle cacheを置かない。
- 実機で記録オン/オフ、アプリ内一覧、一括削除、SAF書き出し後も外部コピーが残ることを確認する。実機未確認は明記する。
- `docs/ROADMAP.md`と`docs/TEST_LOG.md`を更新する。実位置、Cell ID、加入者情報、実機CSVをソース/ドキュメント/fixtureへ含めない。作業後に`git diff --check`とGit差分を確認する。
```
