# Claude Code向け指示: Mt.TAKAO 3号LTルート画面

`web/csv-visualizer/keio-mttakao3/` のLT専用画面を編集するときのデザイン要件です。先にリポジトリの `AGENTS.md` と [`web-dashboard-requirements.md`](web-dashboard-requirements.md) を読み、既存の共通モニター実装を活かしてください。

## 画面の狙い

添付された最新デザイン案のように、走行ルートと携帯網の変化を発表会場でひと目で伝える専用ダッシュボードにします。ルートと時刻表はこの専用ページだけに表示します。日常の散歩/ドライブ向けトップページの情報設計は変えません。

## ルート概要

- 左から右へ `高尾山口 → 明大前 → 新宿` と配置します。時刻は高尾山口11:45着、明大前11:06、新宿11:00発（土休日の公式時刻表）を表示します。
- 紺色の夜景調背景、シアンの明るいルート線/発光、駅の丸いマーカー、駅名と予定時刻を使い、参考画像の色と情報の見せ方に寄せます。
- 選択中の計測時刻が時刻表の運行時間内なら、予定ルート上の位置をマーカーで示します。これは時刻表から計算した予定位置であり、実測GPSとは明確に区別します。
- 「概略・縮尺なし」を明記します。経路の装飾は地理的な正確さを暗示する地図にせず、実測ルートに見える線や架空のセル圏を描きません。
- 実測GPSは既存の地図パネルにのみ描きます。秋葉原の散歩CSVなどルート外データは実際の場所で表示し、京王線の駅/区間に投影しないでください。セル変化イベントも、京王線上で観測されたと確認できない限りルート図へ配置しません。

## 全体の見せ方

- 参考画像の構成を踏まえ、上部にルートと主要指標、下部にRSRPやHTTP応答時間の時系列と時刻表照合を置きます。現在のCSV/BLE共通描画、選択時刻の同期、一覧/詳細表示モードを壊さないでください。
- BLE/CSVの実測値のみをライブ値として表示し、サンプル値を混ぜないでください。BLE接続状態、取得時刻、欠測、接続アンテナエリアの変化（推定）は既存の意味を維持します。
- ページ見出しや副題は、実際に京王ライナーへ乗車していない検証中でも「乗車中」と誤解させない表現にします。
- 地図タイルを表示する場合は既存のOpenStreetMap帰属/外部通信説明を維持し、CSV/GPS/Cell IDを追加送信しないでください。
