# Keio Ride Logger 開発状況

このファイルは現在地と作業ルールの入口です。個別タスクは [`ROADMAP.md`](ROADMAP.md)、実機検証の履歴は [`TEST_LOG.md`](TEST_LOG.md) を参照してください。

## 現在のフェーズ

**フェーズ1: 実機計測の信頼性確認中。** GPSの測位成功後も画面が「受信中」のままになる表示不具合が最新セッションで確認されました。基地局切り替わりは実乗車で未確認です。次に着手するタスクはロードマップ先頭のGPS状態表示修正です。

フェーズ2では、アプリ内ライブ可視化とCSV軌跡ビューアを実データで確認します。詳しい優先順位・完了条件はロードマップを参照してください。

## 計測の主軸

京王ライナー乗車中にAndroidの携帯網・通信状態の変化を記録し、移動との関係を調べます。GPSとセンサーは時刻・移動状態を対応づける補助データです。在圏セルと周辺セルを区別し、APIが返さない値や未確認のhandover・通信応答を推測で補いません。

## 作業環境

変更前にプロジェクトルートと`android-app/AGENTS.md`を読み、Android CLI・SDK・Gradleは既存のDocker/OrbStack環境内で使います。開発はコンテナ内のClaude Code、ホスト側ではCodexが実機画面・CSV・差分を確認する分担です。詳細は [`docs/lt/development-environment.md`](lt/development-environment.md) を参照してください。

## 公開リポジトリとデータ保護

このプロジェクトは公開GitHubリポジトリです。実機計測CSV、正確なGPS軌跡、基地局識別情報、ADBのbugreport/logcat、端末画面のスクリーンショット、生成された会話ログ、署名鍵やトークンを公開差分へ含めないでください。`.gitignore`は今後追加されるファイルを隔離するだけで、すでにGit追跡中のファイルを非公開にはしません。作業前後に`git status --short`と`git ls-files`を確認し、公開前に差分と追加ファイルの内容を点検します。

ローカル専用のログは`.gitignore`対象の[`logs/README.md`](../logs/README.md)に従って保管します。過去のClaude Code会話ログはローカル専用の`docs/logs/`に置き、公開ドキュメントからリンクしません。公開用サンプルCSVは生データと分け、位置・時刻・識別情報を削除または粗粒度化してください。

**公開履歴の注意:** 旧配置の`logs/2026-10-30_a96b6f1f.md`はGit追跡済みで、今回の作業ツリーでは削除扱いです。削除をコミットしても過去の公開コミットからは消えません。確認した範囲では生のGPS座標・Cell ID・認証情報は含まれていませんが、会話ログを今後公開しない方針に合わせて現行ブランチから除きます。過去に秘密情報が含まれていたと判明した場合は、履歴削除と該当資格情報の失効を別途検討します。
